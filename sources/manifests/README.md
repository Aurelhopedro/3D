# Manifestos de fontes

Esta pasta contém manifestos de referência para fontes de assets e ferramentas externas que requerem avaliação manual antes de integração.

## Ficheiros

- `generators.md` — ferramentas geradoras de geometria procedural
- `addons.md` — addons Blender avaliados

## Regra de ouro

Nenhuma fonte é integrada sem:
1. Licença confirmada (no ficheiro LICENSE do repositório, não apenas na página web).
2. Separação clara entre licença do código e licença dos assets produzidos.
3. Registo em `config/libraries.json`.
